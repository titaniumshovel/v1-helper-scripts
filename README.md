# V1 Helper Scripts

A collection of independent helper scripts and tools for Trend Vision One (V1) customers. Each subfolder is a self-contained project with its own README, install steps, and requirements — pick the one you need.

## Contents

| Folder | What it does |
|---|---|
| [`uet-toolkit/`](uet-toolkit/) | CLI toolkit for triaging and remediating unmanaged endpoints in Vision One / Server & Workload Protection (SWP) — classifies stale/needs-install/needs-repair hosts and drives fix payloads against them. |
| [`endpoint-sensor-report/`](endpoint-sensor-report/) | CLI tool that pulls endpoint inventory from the Vision One API, optionally enriches it with SWP agent readiness, and prints/exports a formatted report. |
| [`listDeviceInfo/`](listDeviceInfo/) | Windows utility (prebuilt EXE) that lists connected devices — USB storage, mobile devices, CD/DVD, and wireless adapters — for endpoint triage. |
